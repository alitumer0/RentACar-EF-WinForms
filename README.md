# 🚗 Araç Kiralama Sistemi

Modern bir araç kiralama işletmesi için geliştirilmiş, kullanıcı dostu bir Windows Forms uygulaması.

## 📋 Özellikler

### Kullanıcı Sistemi
- 👥 Admin ve kullanıcı rolleri
- 🔐 Güvenli giriş sistemi
- 📝 Kullanıcı profil yönetimi

### Araç Yönetimi
- 🚙 Detaylı araç bilgileri (Şasi, plaka, marka, model)
- 📊 Araç durumu takibi
- ⚡ Yakıt tipi yönetimi
- 🔍 Araç arama ve filtreleme
- 💰 Fiyatlandırma sistemi

### Müşteri Sistemi
- 👤 Müşteri kayıt ve profil yönetimi
- 🎫 Ehliyet bilgisi ve geçerlilik kontrolü
- 🏥 Müşteri sağlık bilgileri
- 📞 Acil durum iletişim bilgileri

### Kiralama İşlemleri
- 📅 Tarih bazlı kiralama sistemi
- 📈 Kiralama geçmişi
- 💳 Fiyatlandırma
- 📊 Raporlama

## 🛠️ Kullanılan Teknolojiler

- .NET 8.0
- C# 12.0
- Entity Framework Core
- Windows Forms
- MS SQL Server
